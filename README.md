# Studio Representation

Копия съёмочного павильона в Unity, сделанная по 4 фотографиям. Нужна, чтобы показывать клиенту варианты оформления студии.

## Запуск

1. Unity **2022.3 LTS** (подойдёт 2021.3+). Пайплайн рендера встроенный (Built-in), без URP/HDRP.
2. Unity Hub → **Add project from disk** → выбрать папку репозитория.
3. Меню **Studio → Создать сцену студии** (или любая пустая сцена) → **Play**.

Сцену собирать не нужно: при старте `StudioBootstrap` сам строит зал, свет, технику и текущую расстановку.
Без Play геометрию можно посмотреть через **Studio → Построить превью в редакторе**.

## Что есть в зале

| Фото | Что воспроизведено |
|---|---|
| 1 | северная стена из чёрных акустических панелей, галерея на 3.8 м, открытый проём, вентрешётка, красный силовой щит; чёрный занавес слева |
| 2 | белая стена, проход на склад (EXIT, стопки стульев), бежевая кулиса, чёрный занавес; монитор на стойке |
| 3, 4 | северо-восточный угол: драпировка, кабельная стойка, приборы на пантографах с номерами (11, 15, 16, 17, 20, 21, 23, 24) |

Сет как на фото: два серых кресла, круглые деревянные столики, ширмы-сёдзи (белая, оранжевая, серая), камеры на штативах и пьедестале.

Размеры примерные, по фото: 16 × 13 м, высота подвесной решётки 7.3 м. Если есть точный план, поправьте константы в `StudioBuilder.cs`. Координаты всех объектов задаются там же.

## Работа с клиентом

- **Вид**: ракурсы как на фото 1–4, план сверху, два «эфирных» кадра; угол обзора; цвет или картинка на белой стене (логотип, брендинг); цвет пола; скрыть технику и риг для чистого рендера; скриншот (`P`).
- **Объекты**: каталог мебели, декора и техники (кресла, диван, стол ведущего, барные стулья, стеллаж, сёдзи, растения, ковёр, подиум, панель с логотипом, неон, торшер, LED-экран 4×2.25 м, монитор, камеры). Объект можно перетаскивать, вращать, перекрашивать, а на экран или панель поставить картинку.
- **Свет**: общая яркость, цветовая температура (3200 / 4300 / 5600 K), общий свет зала, включение и выключение каждого прибора.
- **Проект**: варианты оформления сохраняются в JSON и открываются заново; сброс к расстановке с фото.

Управление: ЛКМ/ПКМ по пустому месту вращает камеру, Shift+ЛКМ или СКМ двигает её, колесо приближает, WASD перемещает. ЛКМ по объекту выбирает его и тащит, Q/E поворачивают, Del удаляет, Ctrl+D делает копию, Ctrl при перетаскивании включает шаг 25 см. `1–7` переключают ракурсы, `H` скрывает интерфейс.

Скриншоты и проекты лежат в `Application.persistentDataPath` (путь показан в интерфейсе).

## Сборка (exe/app для показа без Unity)

Перед сборкой один раз выполните **Studio → Подготовить проект к сборке**. Материалы создаются из кода, поэтому шейдеры `Standard` и `Sprites/Default` нужно явно добавить в билд, и эта команда это делает.

## Структура

```
Assets/Studio/Scripts/
  StudioBootstrap.cs   точка входа при Play
  StudioBuilder.cs     зал, стены, занавесы, решётка, приборы, расстановка с фото
  PropFactory.cs       каталог объектов (всё из примитивов, без внешних моделей)
  StudioProp.cs        редактируемый объект: цвет, картинка
  StudioMaterials.cs   материалы и процедурные текстуры
  StudioCameraRig.cs   камера и ракурсы
  StudioEditor.cs      интерфейс редактора, сохранение, скриншоты
  Geo.cs               хелперы геометрии (меш занавеса со складками)
  Editor/StudioMenu.cs меню Studio в редакторе
```
