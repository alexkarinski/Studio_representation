# Studio Representation

Копия съёмочного павильона в Unity, собранная по 4 фотографиям. Нужна, чтобы показывать клиенту варианты оформления студии. Открывается в браузере через GitHub Pages и в Unity Editor.

## Запуск на GitHub (веб-версия по ссылке)

**Открыть студию: https://alexkarinski.github.io/Studio_representation/**

Сборку делает GitHub Actions (`.github/workflows/webgl.yml`, [game-ci](https://game.ci)) и публикует её на GitHub Pages:
`https://alexkarinski.github.io/Studio_representation/`

Для сборки нужна лицензия Unity. Бесплатная Personal подходит. Настройка делается один раз:

1. **Получить файл лицензии.** Установите Unity Hub, войдите в аккаунт и активируйте Personal-лицензию (Hub → Preferences → Licenses → Add). Появится файл:
   - Windows: `C:\ProgramData\Unity\Unity_lic.ulf`
   - macOS: `/Library/Application Support/Unity/Unity_lic.ulf`
   - Linux: `~/.local/share/unity3d/Unity/Unity_lic.ulf`
2. **Добавить секреты** в репозитории: Settings → Secrets and variables → Actions → New repository secret:
   - `UNITY_LICENSE`: всё содержимое `Unity_lic.ulf`
   - `UNITY_EMAIL`: email аккаунта Unity
   - `UNITY_PASSWORD`: пароль аккаунта Unity
3. **Включить Pages**: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
4. Открыть Actions → **WebGL build & Pages** → **Run workflow** (или сделать любой push). Первая сборка идёт около 20–30 минут, следующие быстрее за счёт кеша.

На Pages публикуется только ветка по умолчанию. Остальные ветки собираются, и результат можно проверить в логах Actions.

## Запуск в Unity Editor

1. Unity **2022.3 LTS** (версия в `ProjectSettings/ProjectVersion.txt`), встроенный рендер (Built-in).
2. Unity Hub → **Add project from disk** → папка репозитория. При первом открытии Unity импортирует модели и сама выставит настройки: Linear-цвет, WebGL2, сжатие для Pages.
3. Меню **Studio → Открыть сцену студии** → **Play**.

Локальная веб-сборка: **Studio → Собрать WebGL**, результат в `build/WebGL/WebGL`. Открывать её нужно через локальный веб-сервер, а не двойным кликом.

## 3D-модели

Мебель и декор — настоящие 3D-модели с [Poly Haven](https://polyhaven.com/models) (лицензия CC0, коммерческое использование разрешено): кресла, диваны, пуф, журнальные и приставные столики, барные стулья, стеллажи, комод, растения, ваза, подушки, картина в раме. Они лежат в `Assets/Studio/Resources/Models` вместе с PBR-текстурами (альбедо, нормали, металл/гладкость).

Модели добавляются через `python3 tools/prepare_models.py <id>` (id берётся из адреса страницы модели на Poly Haven). Затем нужно добавить строку `Model(...)` в `PropFactory.Catalog`.

Шрифт интерфейса: PT Sans (ParaType, SIL Open Font License), лежит в `Assets/Studio/Resources/Fonts`.

Студийная техника (камеры, световые приборы, пантографы, LED-экран), ширмы-сёдзи и сами стены собраны из геометрии в коде. Готовых бесплатных CC0-моделей этой техники нет.

## Работа с клиентом

- **Вид**: ракурсы фото, план сверху, эфирные кадры; цвет или картинка на белой стене (логотип, брендинг, хромакей); цвет пола; скрыть технику и риг; скриншот (`P`, в браузере скачивается PNG).
- **Объекты**: каталог (3D-модели и студийные объекты). Объект можно перетаскивать, вращать и тонировать, а на экран, панель или картину загрузить изображение.
- **Свет**: яркость, цветовая температура 2700–6500 K, общий свет, включение и выключение каждого прибора.
- **Проект**: сохранение вариантов. В браузере варианты хранятся локально, и их можно скачать файлом `.json`.

Управление: ЛКМ/ПКМ по пустому месту вращает камеру, Shift+ЛКМ или СКМ двигает её, колесо приближает, WASD перемещает. ЛКМ по объекту выбирает его и тащит, Q/E поворачивают, Del удаляет, Ctrl+D делает копию. `1–7` переключают ракурсы, `H` скрывает интерфейс.

## Структура

```
.github/workflows/webgl.yml     сборка WebGL + GitHub Pages
Assets/Plugins/WebGL/           мост в браузер (загрузка картинок, скачивание файлов)
Assets/Studio/Resources/Models/ 3D-модели Poly Haven
Assets/Studio/Scripts/
  StudioBootstrap.cs   точка входа при Play
  StudioBuilder.cs     зал, стены, занавесы, решётка, приборы, расстановка с фото
  PropFactory.cs       каталог объектов
  ModelLibrary.cs      загрузка и нормализация 3D-моделей
  StudioEditor.cs      интерфейс, сохранение, скриншоты
  StudioCameraRig.cs   камера и ракурсы
  Editor/              импорт моделей, сборка WebGL, меню Studio
tools/prepare_models.py         скачивание и подготовка моделей
```
